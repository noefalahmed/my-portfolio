2026-06-28 Typography Message bubble font size 13px→15px (.ma-bubble) Below 16px minimum for body text. Most-read element in the UI.

2026-06-28 Typography Removed Inter as a third font family. All Inter usages replaced with IBM Plex Sans. 3 font families is one too many. Inter was only used for labels/captions — IBM Plex Sans covers this. Reduces 1 font load.

2026-06-28 Typography caption floor 10.8px→12px. Font updated from Inter → IBM Plex Sans. 10.8px is below the 12px minimum for any text. Also aligns with Inter removal.
